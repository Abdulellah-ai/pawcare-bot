# باو كير (PawCare): بوت تلجرام لعيادة بيطرية مع لوحة إدارة

بوت يجيب العملاء ويحجز المواعيد ويحوّل الحالات الحساسة لفريق العيادة، بلوحة تحكم لمتابعة كل شيء. العيادة وهمية (عرض تجريبي): أسعارها وأرقامها وبريدها قيم رمزية.

> **حالة المشروع:** عرض تجريبي (demo) يعمل فعليًا، وليس منتجًا جاهزًا لعملاء حقيقيين. نُشر هنا لطلب الملاحظات.

## ماذا يفعل
- **يجيب فورًا** عن الأسعار والدوام والخدمات من «ملف معرفة» يُدار من اللوحة، ولا يخترع معلومة غير موجودة فيه.
- **يحجز المواعيد:** يجمع الاسم والهاتف والحيوان والسبب، ويحفظ مسودة الحجز 48 ساعة إن توقف العميل.
- **يفهم الرسائل الصوتية ويردّ بصوت** (حتى 60 ثانية)، مع حارس يتحقق مما نُطق فعلًا.
- **يحوّل للموظف** عند الشكوى أو الطلب الصريح أو الحالات الطبية الحساسة، في مجموعة تلجرام لكل حالة فيها موضوع (Topic) مستقل. وإن سكت الموظف ساعتين يعود العميل للبوت.
- **الطوارئ حتمية:** فرز بالكلمات في الكود قبل النموذج، ثم رد ثابت وتنبيه فوري.
- **لا يشخّص ولا يصف جرعات دواء**، ولا يؤكد حجزًا أبدًا (الموظف وحده يؤكد).
- **لوحة إدارة** (عربي RTL): نظرة عامة، المحادثات، الحجوزات، التحويلات، التقارير، تعديل أسلوب البوت ومعرفته، المراقبة.

## البنية
```
العميل ─► تلجرام ─► n8n (Ingress ─► CustomerTurn ─► ردّ نصي/صوتي)
                         │ فرز طوارئ حتمي + كشف حقن قبل النموذج
                         ▼
           OpenAI (ردود، تفريغ، صوت)      Supabase (Postgres + RLS)
                         │ تحويل
                         ▼
        مجموعة الموظفين (موضوع لكل حالة) ◄─► اللوحة (Next.js على Cloudflare Workers)
```
| المسار | المحتوى |
|---|---|
| `workflows/defs/` | تعريف workflows الـn8n (كود يُبنى ويُنشر عبر API) |
| `workflows/shared/` | الفرز الحتمي، كشف الحقن، قواعد البرومبت الثابتة، أسماء المواضيع، HMAC، واختباراتها |
| `workflows/testing/` | فحص شامل (`smoke.cjs`، 12 حالة) ومقارنات النماذج |
| `workflows/spikes/` | تجارب أولية للتحقق من إمكانيات n8n والنماذج |
| `dashboard/` | لوحة الإدارة (Next.js 16، Supabase Auth + RLS + RPC) |
| `tools/` | أدوات: n8n API، تلجرام، نقل بين خوادم، بناء Cloudflare |
| `scripts/` | زرع إعدادات البوت الأولية |
| `docs/` | التصميم والقرارات، ملاحظات مؤجلة، دليل النقل |
| `02-knowledge-base.md` | ملف المعرفة المصدر (قيم تجريبية) |
| `03-test-scenarios.md` | سيناريوهات الاختبار ومعايير النجاح |

## المبادئ التصميمية
1. **النموذج يقترح والكود يقرر:** الطوارئ والتحويل وإدّعاءات تأكيد الحجز تُنفَّذ بالكود، لا بتعليمة في البرومبت وحدها.
2. **طبقات البرومبت:** نواة ثابتة (السلامة) أعلى من الأسلوب، والأسلوب أعلى من المعرفة، ورسالة العميل بيانات لا أوامر.
3. **الالتزام بالرد قبل المعالجة:** كل رسالة تُسجَّل (مفتاح فريد) قبل أي استدعاء للنموذج، ورد احتياطي جاهز.
4. **أقل صلاحية:** n8n يتصل بقاعدة البيانات بدور محدود، واللوحة تكتب عبر دوال `SECURITY DEFINER` مع فحص مدير وسجل تدقيق.
5. **المساعد داخل اللوحة بلا أدوات:** يقترح نصًا فقط، والنشر بنقرة مدير مع فحص حتمي لعبارات الحقن.

## التشغيل (مختصر)
المشروع يحتاج حسابات: n8n (مستضاف ذاتيًا)، وSupabase، وOpenAI، وبوت تلجرام، وCloudflare للوحة. المتغيرات المطلوبة مدرجة في `.env.example`، ولا تُرفع الأسرار أبدًا (مجلد `.local/` وملفات `.env` مستثناة من git).

```bash
cd dashboard && npm install && npm run dev      # اللوحة محليًا على المنفذ 3000
node workflows/deploy.cjs                        # نشر workflows إلى n8n (بعد ضبط المتغيرات)
node tools/cf-build.cjs --deploy                 # بناء ونشر اللوحة على Cloudflare Workers
```
قبل التشغيل: ضع رقم مجموعة الموظفين في `workflows/defs/errors.cjs` (القيمة الحالية رمزية).

## حدود معروفة (بصراحة)
- **ترحيلات قاعدة البيانات غير مضمّنة في هذا المستودع.** المخطط موصوف في `docs/2026-10-01-pawcare-bot-design.md` لكنه لا يُنفَّذ بأمر واحد بعد.
- **لهجات التفريغ الصوتي الحقيقية لم تُختبر**؛ اختباراتنا بصوت مولَّد آليًا، وفهم اللهجة الأردنية ليس مضمونًا.
- **كلفة الرسالة الصوتية غير مقيسة** (الرد النصي ≈ $0.00045، قياس فعلي).
- **مسودة حجز واحدة لكل محادثة**: حيوانان في حجزين متتاليين يتعاقبان.
- **لا فحص بالكود يقارن أرقام الرد بالمعرفة**: منع اختلاق الأسعار يعتمد على البرومبت والمعرفة.
- **الأسئلة الشائعة وتقارير أداء الموظفين** معروضة في اللوحة كـ«قريبًا» ولم تُبنَ بعد (انظر `docs/`).
- **صفحة التقارير الإحصائية** جُرّبت على بيانات صغيرة.
- **أسماء نماذج OpenAI المذكورة** كما في وقت الكتابة؛ تحقق من توفرها وأسعارها.
