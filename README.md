# مشروع شات بوت عيادة بيطرية (عرض تجريبي للعميل)

بوت تلجرام (n8n + Supabase + OpenAI) مع لوحة إدارة (Next.js). العيادة وهمية: **باو كير – PawCare**.

## الهيكل
| المسار | المحتوى |
|---|---|
| `02-knowledge-base.md` | ملف المعرفة المصدر (يُزرع في قاعدة البيانات كإصدار 1، ثم يُدار من اللوحة) |
| `03-test-scenarios.md` | أكثر من 50 سيناريو اختبار ومعايير نجاح العرض |
| `docs/2026-10-01-pawcare-bot-design.md` | التصميم والقرارات ونتيجة الـ Spike والمخاطر |
| `dashboard/` | لوحة الإدارة (Next.js 16, عربي RTL, ليلي/نهاري, Supabase Auth + RLS + RPC) |
| `workflows/shared/` | وحدة الفرز الحتمي للطوارئ وكشف الحقن + اختباراتها (`node --test`) |
| `tools/` | `n8n-api.cjs` (REST n8n)، `tg.cjs` (Telegram بترميز UTF-8) |
| `scripts/` | `seed-bot-config.cjs` (زرع الإصدار 1 للأسلوب والمعرفة) |
| `.local/` | أسرار محلية (مستثناة من git). **لا تُشارك** |

## ملاحظات
- الأسعار تجريبية (لم تنشر أي عيادة أسعارها). رقم الهاتف والبريد وهميان.
- تشغيل اللوحة محليًا: `cd dashboard && npm run dev` (المنفذ 3000)، المتغيرات في `dashboard/.env.local`.
- فحص الفرز: `node --test workflows/shared/triage.test.cjs`.
